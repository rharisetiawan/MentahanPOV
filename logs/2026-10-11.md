## Yang dikerjakan
1. **Liveness:** `core/heartbeat.py` + job heartbeat tiap 5 menit di bot,
   pesan Telegram saat startup ("online lagi, sempat mati X"), endpoint
   `/heartbeat` (tanpa auth, 1 angka) di `dashboard.py`,
   `scripts/watchdog.py` (stdlib only, dijalankan dari mesin LAIN),
   `HEARTBEAT_PING_URL` untuk dead-man's switch (healthchecks.io).
2. **Disk:** `core/cleanup.py` (aturan tunggal) dipakai bot (setelah tiap
   run, harian jam `CLEANUP_HOUR`, saat disk < `DISK_PRESSURE_FREE_GB`
   dengan retention dilewati + lantai 30 menit), `/cleanup` + tombol,
   guard sebelum download (`UPLOAD_MIN_FREE_MB`), rincian di `/status`.
   `scripts/cleanup_storage.py` jadi CLI tipis.
3. **TikTok:** `TikTokPostError`/`TikTokRemoteError` membawa screenshot;
   worker mengirim `screenshot_b64`; main.py memarkir di `state/debug/`;
   bot mengirim foto sebelum kit manual. Path debug pakai
   `tempfile.gettempdir()`, bukan `/tmp` literal.
4. **OAuth:** `granted_at` dicatat di file token → `/status` menghitung
   mundur & warning ~1.5 hari sebelum mati; `scripts/reauth_google.py`
   (redirect 127.0.0.1 → bug IPv6 Windows hilang, lanjut ke service
   berikut kalau satu batal). `GOOGLE_TOKEN_MAX_AGE_DAYS`.
5. **Insights:** `core/insights.py` (24h/72h, YouTube butuh
   `YOUTUBE_API_KEY`), `/insights`, tabel di dashboard, dan hook terbaik
   masuk prompt Gemini (`{{TOP_HOOKS_BLOCK}}` di `prompts/sop_v3.txt`;
   prompt identik dengan sebelumnya bila data < `INSIGHTS_MIN_SAMPLES`).
6. **Jadwal:** tombol 📅 Jadwalkan, `/jadwal`, jadwal disimpan di state
   (`scheduled_at`) dan di-restore saat bot start; file terjadwal kebal
   dari cleanup.
- Pendukung: 91 unit test di `tests/` (unittest, tanpa dependensi baru),
  ruff bersih, `.env.example`, DEPLOYMENT.md, CONTRIBUTING.md,
  `admin/env_schema.py` (mask `*_PING_URL`).
